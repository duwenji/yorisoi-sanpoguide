{{!
  散歩の友: 1時間以内に天気が崩れる予報のとき（雷雨・強い雨・雨や雪の降り始め。同じ種類は1時間あける。
  話しかけの頻度に関係なく話す。判定は WeatherChangeDetector）。
  変数:
    description   予報の天気（雷雨・強い雨・雨・霧雨・雪など）
    minutes       崩れるまでのおよその分数（5分単位）。10分未満なら null（まもなく）
    thunder       雷雨になるとき true
    heavy_rain    強い雨になるとき true
    rain          雨・雪が降り始めるとき true
}}
# 出来事
天気予報によると、{{#minutes}}あと{{minutes}}分ほどで{{/minutes}}{{^minutes}}まもなく{{/minutes}}{{description}}になりそうです。
{{#thunder}}
雷のおそれがあるので、早めに建物の中に入れるよう、落ち着いて伝えてください。木の下での雨宿りは危ないことも添えてください。
{{/thunder}}
{{#heavy_rain}}
強い雨になりそうなので、雨宿りできる場所や帰り道を考えるよう伝えてください。
{{/heavy_rain}}
{{#rain}}
傘の用意や、雨宿りできる場所を気にかけるよう、軽く伝えてください。
{{/rain}}
予報なので外れることもあります。断定せず、怖がらせないように、短く伝えてください。
