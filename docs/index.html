散策ガイド

一緒に歩きながら、周りのスポットを案内し、その時々の状況に合わせて話しかける Android アプリです。

主な機能

  • スポットの案内: 現在地の周りの史跡・寺社・公園・博物館などを地図と一覧に出し、AI がガイドのように解説して読み上げます
  • 散策モード: 歩いている間、スポットに近づいたとき・休憩したとき・天気が崩れそうなとき・日の入りが近いときに、音声で話しかけます
  • 散策に役立つ施設: トイレ・水飲み場・自動販売機・休憩所・ベンチを地図に出し、必要そうなときに知らせます
  • チャンネル: 標準・歴史探訪・自然観察・グルメの旅・ショッピング・しずかに から、語り手と話題を選べます
  • 散策前のプラン: テーマ・時間・距離を選び、立ち寄り先を決めてから歩けます
  • 散歩の記録: 日時・距離・経路・案内したスポットを端末の中に残し、あとから振り返れます

使うときに必要なもの

  • Android 端末と、位置情報の許可
  • 解説と話しかけに使う生成AI サービスの API キー（設定の画面で入れます）

プライバシー

運営者が散策者の情報を受け取るサーバーはありません。アカウントの登録、利用状況の解析、広告もありません。詳しくはプライバシーポリシーをご覧ください。
