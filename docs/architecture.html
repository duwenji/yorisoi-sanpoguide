考え方 · チャンネルと関係者

同じ散歩を、違う体験に切り替える

チャンネルは、語り手・話題・話す場面・話す量・トーン・背景音をまとめて切り替えるものです。ラジオの局のように散歩の途中でも切り替えられます（コード上の名前 Station はこのたとえから）。図 2〜4・7 の流れは、どれも選んでいるチャンネルを見て動きます。関係者は、散策者・チャンネル提供者・素材提供者と、そのあいだで審査と署名をする運営です（docs/stakeholders.md）。

図 1 · 全体

画面とサービスは、SanpoApp が持つ共有部品を使う

DI ライブラリは使っていません。SanpoApp.onCreate() が部品を 1 つずつ作り、画面の ViewModel と WalkService は (application as SanpoApp).spots のように直接取り出します。

図 2 · 散策モード

話しかけるまでの流れ

位置が更新されるたびと、一定間隔のタイマーで maybeTalk() が呼ばれます。判定は上から順に行い、最初に当たった 1 件だけを話します。

スポットが近くに複数あるとき

案内範囲（ANNOUNCE_RADIUS_M = 60m）はユーザーの現在地を中心にした円で、スポットごとの範囲ではありません。スポット同士の距離は判定に使わないので、「A が B の近くにある」こと自体は A の案内に影響しません。

  • 1 回の判定で案内するのは 1 件だけ。notability（Wikipedia/Wikidata タグで +2、主要カテゴリで +1）に、チャンネルの「優先する話題」の種類なら +2 を足し、高い方、同点なら近い方を選びます（companion/SpotChooser.kt）。チャンネルが除く種類は候補にしません。
  • 選ばれなかったスポットは候補に残り、次の判定（30 秒ごと）で次の条件をすべて満たせば案内されます：前回のスポット案内から TalkLevel.spotGapMs 以上経った／まだ 60m 以内にいる／2 分以上とどまっていない／読み上げ中でない。
  • 間隔が空く前に 60m の外へ出たら、そのときは案内されません。案内済み（talkedAbout）にはならないので、また近づけば案内されます。
  • 今回の散歩で案内したスポット（同じ ID、または同じ名前で近い位置）は候補から外れます。過去の散歩で訪れたスポットは、再訪の一言の候補になります。
  • スポットの通知は 1 枠（SPOT_NOTIFICATION_ID）を使い回すため、新しい案内が前の通知を置き換えます。
図 3 · スポット解説

地図でスポットをタップしたとき

解説と写真は別々に取りに行きます。解説は「AI サービス・モデル・チャンネル（版を含む）・解説の長さ・スポット・位置情報を送る設定」の組み合わせでキャッシュされるため、同じ条件で料金がかかるのは 1 回だけです。解説の役割・重点・長さは、選んでいるチャンネルから入ります。

図 4 · 雰囲気

1 つの「雰囲気」を画面・音・話し方で共有する

MoodSource が 3 つの入力をまとめて現在の Mood（時間帯 × 季節 × 空模様 × 場所）を作り、4 か所がそれを読みます。

図 5 · 地図

ルートと向き

地図には、案内中のスポットまでの道と、ユーザーの向いている方向を描きます。どちらも画面（MainViewModel と SpotMap）だけの処理で、WalkService は案内したスポットを CompanionFeed.guiding に出すだけです。

地図の種類

設定の「地図」（GuideSettings.mapStyle）で、国土地理院の 4 種類（標準・淡色・写真・標高）と Google マップの 2 種類（地図・航空写真）を選びます。

  • 設定値は MainViewModel.map が MapTiles に変換し、SpotMap が osmdroid の地図画像（ui/MapTiles.kt）を差し替えます。
  • Google は散策者自身の API キーで Map Tiles API のセッションを作り（GoogleMapTiles.session()、2 週間有効）、地図画像の URL に付けます。
  • Google の地図を表示している間は、規約に従い左下にロゴ、右下に表示範囲の出典を出します。出典は地図の移動が止まってから viewport API で取得します（onMapViewport()）。
  • キーが未設定・無効・接続できないときは地理院の標準地図にし、理由を地図の上に出します。

AI に送る位置情報

設定「AI に緯度経度と歩いた経路を送る」（GuideSettings.shareLocationWithAi、既定はオフ）をオンにしたときだけ、次を AI に送ります。

  • スポット解説（guide/user）：スポットの緯度経度（coords）。GuidePrompt.spotVars() で作ります。
  • 話しかけ（companion/situation）：現在地の緯度経度と、今回歩いた経路を最大 20 点に間引いたもの（location）。WalkCompanion.situationVars() で作ります。
  • 解説のキャッシュは設定のオン・オフで分けています。
図 6 · チャンネル

選んだチャンネルが、解説・話しかけ・話す判断を変える

選んだチャンネルが、アプリの中でどこに効くかを追います（考え方は冒頭の「チャンネルと関係者」、設計は docs/channels.md、形式は docs/channel-package-format.md）。チャンネルの中身は、語り手・話題・話す場面・頻度・解説の長さ・優先する話題・トーン・背景音のひとまとまりです。

図 7 · 素材ときっかけ

チャンネルが決めた場面で、決めた素材を出す

チャンネルは、きっかけ（スポット・地点・出来事）と見せ方を決め、素材（文字・画像）を出せます（docs/adr/ADR-002-material-producers.md、docs/channel-package-format.md・docs/material-producer-api.md）。素材は、組み込みの素材提供者・チャンネルに同梱の素材・リストに載った素材集から、共通の IF（Producer）で取り出します。
