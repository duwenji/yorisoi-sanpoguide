## 実際に歩いての確認

天気の急変・日の入り・施設の話しかけは、条件がそろわずエミュレータでは流れていない。

- [ ] 安全・施設の案内が実際に流れるか。しきい値の既定値（今は仮）を見直す。話しかけの頻度ごとに既定値を変えるかも検討
- [ ] 雷の予告の通知を、強い雨にも出すか
- [ ] 雰囲気: 場所の種類の推定が合っているか（とくに「史跡」: 石碑などの `historic` が多い場所では、寺社の近くでも史跡と判定されやすい）。AI のトーンの変わり方
- [ ] 背景音: 実機のイヤホン（有線・Bluetooth）での音質・音量・切り替えのフェード、イヤホンを外したときの停止、他のアプリで音楽を再生したときの停止。電池の消費（22,050Hz・モノラルの合成を 50ms ごと）
- [ ] チャンネル: 各チャンネルの語り口、優先する話題の加点（+2）、きっかけの出方。グルメの旅・ショッピングの店の検索
- [ ] Overpass の失敗の頻度を集計し、自前・商用のサーバーを検討する材料にする（[共通の検討事項](#共通の検討事項)の「公開サーバーの負荷」）。Overpass の予備のサーバーの証明書が Android 11 で信頼されない件も

## 位置に紐づく秘密メッセージ

特定の場所に来たときだけ読める・聞けるメッセージ。ジオキャッシュのように、場所に「置いて」おき、その場所に来た人が見つける。

利用場面の例:
- 自分宛て: 「1 年後にまたここに来たら読む」メッセージ
- 家族・友人宛て: 特定の人だけが開けるメッセージ
- 公開: その場所を訪れた人なら誰でも見つけられる（宝探し、イベント）
- チャンネルと組み合わせた、店舗やイベントの隠しコンテンツ

自分宛てだけならサーバーなしで作れる（`HistoryStore` と同じく端末内に保存）。先にここだけ切り出して着手できる。他人宛て・グループ・公開のサーバー API は [secret-messages-api.md](secret-messages-api.md)（API-001）で決めた。接続先は URL で設定し、API に準拠していればサーバーの実装方法・置き場所は問わない。

- [ ] メッセージを置く（現在地、または地図上の地点を指定）
- [ ] 開ける条件（半径◯m 以内、日時・期間、特定の相手、合言葉）
- [ ] 近くに来たら通知し、話しかけで知らせる
- [ ] 形式（テキスト・音声・写真）
- [ ] 準拠テスト: 任意のサーバーの URL に対して流せるテスト（API-001 の確認観点 V-01〜V-18）。Kotlin（JVM）＋ Tink を想定
- [ ] 参照実装のサーバー（開発・テスト用。技術は自由）
- [ ] アプリの実装（設定画面の「メッセージサーバー」欄、鍵の作成と QR コードの交換、送受信）

関連ファイル: 契約書（正本）[secret-messages-api.md](secret-messages-api.md)、OpenAPI [api/sanpo-messages.openapi.yaml](api/sanpo-messages.openapi.yaml)（検証: `docs/api` で `npx @redocly/cli lint sanpo-messages.openapi.yaml`）

決めること:
- 位置の偽装（位置情報の偽装アプリ）で開けられることへの対策をどこまでやるか
- 公開メッセージの不適切な投稿への対策（通報・削除）
- 私有地・危険な場所に置かせない配慮
- サーバーを持つかどうか（他の項目とも共通の判断）

## 共通の検討事項

- **サーバーの要否**: 他人宛ての秘密メッセージはサーバーが必要。アプリはサーバーを持たず、端末と公開 API と承認済みチャンネル・リストだけで動いている。項目ごとにばらばらに決めず、1 つの判断（ADR）としてまとめて決める
- **収益化**: 広告、有料プラン、提携。宣伝は審査した素材でだけ表示つきで認める（ADR-002 D-29〜D-36）。既存の広告 SDK は、位置情報を外部に送らない方針（API-003 F-10）と合わないので使わない方向
- **プライバシー**: 位置情報を外部に送る範囲が広がる。README の「散歩の記録の扱い」を更新し、同意を取る
- **安全**: 歩きながら画面を見させない。音声中心の案内を基本にする
- **電池・通信量**: 画像・音声の取得と再生が増えるため、散策モードでの消費を計測する
- **公開サーバーの負荷**: Overpass・Open-Meteo は公開サーバーを使っている。散策者が増える前に利用ポリシーを確認し、自前のサーバーや商用のサービスを検討する
