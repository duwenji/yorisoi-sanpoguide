# Play Console の申告

Google Play Console の「アプリのコンテンツ」に入れる答え。アプリが送る情報・権限を変えたら、ここと [privacy-policy.md](privacy-policy.md) を合わせて直す。

## アプリの基本

| 項目 | 答え |
|---|---|
| パッケージ名 | `io.github.duwenji.yorisoi.sanpoguide` |
| 署名 | Play App Signing。`release.jks` をアップロード鍵にする |
| プライバシーポリシー | https://duwenji.github.io/yorisoi-sanpoguide/privacy-policy |
| 広告 | 含まない |
| アプリへのアクセス | 制限なし（ログインなし）。AI の解説には散策者自身の API キーが要る。審査用の説明: 「API キーがなくても、地図・周辺のスポット・天気・散策の記録は使える。AI の解説と話しかけは、設定で AI サービスと API キーを入れたときだけ」 |
| 対象年齢 | 18 歳以上（子どもを対象としない） |
| カテゴリ | アプリの「旅行＆地域情報」。地図＆ナビ・健康＆フィットネスにはしない（健康の申告「いいえ」と食い違う）。タグは Travel guide・Travel & local・Maps & navigation の 3 つ。Activity tracker・Personal assistant は付けない |
| 連絡先の詳細 | ウェブサイトは Pages のトップ https://duwenji.github.io/yorisoi-sanpoguide/ 。メールアドレスは必須で公開される（この文書には書かない）。電話番号は任意で、入れると公開されるので空欄にする |
| ニュースアプリ・政府のアプリ・金融・健康 | いいえ |
| コンテンツのレーティング | 質問票は「暴力・性的・薬物・賭博・ユーザー同士の交流・位置の共有（ほかのユーザーへ）」すべていいえ。AI が生成する文章を表示するので、「ユーザーが生成したコンテンツ」はいいえ、生成 AI の利用ははい |

## ストアの掲載情報

**[ユーザーを増やす] > [ストアの掲載情報]** に入れる内容。カテゴリ・タグ・連絡先の詳細は [アプリの基本](#アプリの基本) の表のとおり。言語は日本語だけ（英語の掲載情報は、アプリが英語に対応してから足す）。カスタムのストアの掲載情報は作らない。

| 項目 | 制限 | 入れるもの |
|---|---|---|
| アプリ名 | 30 文字 | `散策ガイド`。「AI」「無料」などの宣伝語を足さない（キーワードの詰め込みになる） |
| 簡単な説明 | 80 文字 | [下の文](#簡単な説明) |
| 詳しい説明 | 4,000 文字 | [下の文](#詳しい説明) |
| アプリのアイコン | 512×512、32 ビット PNG、1MB 以下 | アプリのアイコン（`ic_walk`）を 512px で書き出す |
| フィーチャー グラフィック | 1024×500、JPEG か 24 ビット PNG（透過なし）、15MB 以下 | アプリ名と、歩く人と地図の絵 |
| スマートフォンのスクリーンショット | 2〜8 枚、辺は 320〜3840px、縦横比 2:1 まで | [下の 6 枚](#スクリーンショット) |
| タブレット・Chromebook・Android XR のスクリーンショット | 任意 | 出さない（スマートフォン向け） |
| 動画 | 任意（YouTube の URL） | 出さない |

説明文には、星・絵文字・「No.1」などの誇張を使わない。API キーが要ることと、その利用料が各サービスから散策者に請求されることは必ず書く。位置を外部に送ることは [データ セーフティ](#データ-セーフティ) の申告と合わせる。

### 簡単な説明

```text
歩きながら周りのスポットを案内し、天気や休憩に合わせて声で話しかける散策のお供
```

### 詳しい説明

```text
散策ガイドは、一緒に歩きながら周りのスポットを案内し、その時々の状況に合わせて話しかける散策のお供です。

■ スポットの案内
現在地の周りの史跡・寺社・公園・博物館などを地図と一覧に出します。スポットを選ぶと、AI がガイドのように解説し、読み上げます。写真が登録されているスポットでは、作者とライセンスとともに写真も表示します。

■ 散策モード
散策を始めると、歩いている間に音声で話しかけます。
・スポットに近づいたとき（前に訪れた場所なら、前回を踏まえた短い一言）
・しばらく休憩したとき
・1 時間以内に雨や雷雨になりそうなとき
・日の入りが近づいたとき
・散策の始まりと終わり

■ 散策に役立つ施設
トイレ・水飲み場・自動販売機・休憩所・ベンチを地図に出します。歩いた時間や気温、天気に合わせて、必要そうなときに近くの施設を知らせます。

■ チャンネル
標準・歴史探訪・自然観察・グルメの旅・ショッピング・しずかに から、語り手と話題を選べます。

■ 散策前のプラン
テーマ・時間・距離を選び、近くの立ち寄り先を決めてから歩けます。

■ 散歩の記録
日時・距離・経路・案内したスポットを端末の中に残し、あとから振り返れます。

■ 使うときに必要なもの
・位置情報の許可
・AI の解説と話しかけには、生成AI サービス（Anthropic・OpenAI・Google・DeepSeek、または OpenAI 互換のサービス）の API キーが必要です。設定の画面で入れます。API キーの利用料は、各サービスから散策者に請求されます。
・API キーがなくても、地図・周りのスポット・天気・散策の記録は使えます。

■ プライバシー
運営者が散策者の情報を受け取るサーバーはありません。アカウントの登録、利用状況の解析、広告もありません。散歩の記録と API キーは端末の中だけに保存します。位置は、スポットや天気を調べるために外部のサービスへ送ります。AI サービスには、既定では緯度経度と歩いた経路を送りません。詳しくはプライバシーポリシーをご覧ください。

地図データ © OpenStreetMap の貢献者
```

機能・送る情報・対応する AI サービスを変えたら、この文と [Pages のトップ](index.html) を合わせて直す。

### スクリーンショット

縦長の 1080×1920 以上を、エミュレータで観光地（浅草・鎌倉など）に位置を設定して撮る。API キーと自宅の周りの位置は写さない。

1. 地図と周りのスポットの一覧（メイン画面）
2. スポットの AI 解説と写真
3. 散策中の話しかけのカード
4. 散策に役立つ施設が地図に出ているところ
5. チャンネルを選ぶ画面
6. 散歩の記録

## データ セーフティ

Google の定義では、端末から外に送るものは、送り先が運営者のサーバーでなくても「収集」になる。散策ガイドは運営者のサーバーを持たないが、外部サービスに送る位置などを「収集」として申告する。

| 質問 | 答え |
|---|---|
| 必須のデータを収集・共有するか | はい |
| 送るデータはすべて転送時に暗号化されるか | はい（通信はすべて HTTPS） |
| データの削除をリクエストできるか | 運営者はデータを保管しないので、アプリの中で消せる（記録の画面・アプリの削除）。「ユーザーがデータの削除をリクエストできる手段を提供する」ははい |

### 収集するデータ

| データの種類 | 収集 | 共有 | 一時的な処理 | 任意か | 目的 |
|---|---|---|---|---|---|
| 位置情報 > おおよその位置情報 | はい | いいえ | はい | 必須 | アプリの機能 |
| 位置情報 > 正確な位置情報 | はい | いいえ | はい | 必須 | アプリの機能 |
| アプリのアクティビティ > その他のユーザー作成コンテンツ（散策の状況のまとめを AI へ） | はい | いいえ | はい | 任意（API キーを入れたときだけ） | アプリの機能 |

- **共有はいいえ**: Overpass・OSRM・Open-Meteo・AI サービスなどへの送信は、散策者が求めた機能を提供するためのもので、送り先は位置を別の目的に使う相手として渡していない。AI サービスへは散策者自身の API キーで、散策者が選んだサービスに送る
- **一時的な処理**: 運営者はどれも保管しない。各サービスでの扱いは、それぞれのポリシーに従う（プライバシーポリシーの「外部サービスへの送信」）
- **申告しないもの**: 散歩の記録・設定・API キーは端末の外に出ない（バックアップ・端末間の移行もしない）。個人情報（名前・メールアドレス）、端末の ID、アプリの診断情報は扱わない

## フォアグラウンドサービスの申告

| 項目 | 答え |
|---|---|
| 種類 | 位置情報（`foregroundServiceType="location"`、`FOREGROUND_SERVICE_LOCATION`） |
| バックグラウンドの位置情報の権限 | 求めない（`ACCESS_BACKGROUND_LOCATION` なし。散策者が画面で「散策をはじめる」を押したときに始める） |
| 説明 | 散策者が「散策をはじめる」を押してから「散策を終える」を押すまで、画面を閉じても現在地を追い、近づいたスポットの解説と、歩いた距離・経路の記録をする。散策中は通知を出し続け、通知の「終了」からも終えられる |
| 散策者への影響 | 位置を追うのをやめると、画面を閉じている間のスポットの案内と、散歩の記録が途切れる |
| 動画 | 「散策をはじめる」→ 通知が出る → 画面を閉じる → スポットに近づくと案内が出る → 「散策を終える」の流れを撮り、YouTube（限定公開）の URL を入れる |
