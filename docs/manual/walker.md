# SanpoGuide: 散策者の手引き

[SanpoGuide の手引き](README.md) ＞ 散策者の手引き

対象は SanpoGuide（散策ガイド）の Android アプリです。

散策ガイドは、一緒に歩きながら近くの史跡・寺社・公園などを案内し、天気や時間に合わせて話しかけるアプリです。この手引きでは、はじめの設定から散歩、チャンネルの選び方、困ったときまでを説明します。

## 1. はじめに用意するもの

| もの | 要るか | 説明 |
|---|---|---|
| Android 8.0 以上の端末 | 必須 | 位置情報（GPS）が使えること |
| イヤホン | 勧める | 話しかけと背景音を聞くため。背景音は既定でイヤホンのときだけ流れる |
| AI サービスの API キー | 任意 | 運営の AI を使うなら要らない。自分のキーで使うときは Claude・DeepSeek・OpenAI・Gemini、または OpenAI 互換のサービス |
| Google Maps Platform の API キー | 任意 | Google の地図・航空写真を使うときだけ |

運営の AI は運営が費用を持ち、1 日に使える回数が決まっています。自分の API キーを使うときは、利用料金がそのキーのアカウントに請求されます。どちらの場合も、アプリの運営者には何も払いません。

## 2. はじめての設定

1. アプリを開き、「位置情報を許可する」を押して位置情報を許可する（Android 13 以上では通知も許可する。散策中の常駐の通知とスポットの案内に使う）
2. 右上の歯車（設定）を開く
3. 「AI」の欄で、使う AI を選ぶ
   - 「運営の AI（設定不要）」: そのまま使える。今日の残りの回数が出る
   - 「自分の API キー」: 「AI サービス」を選び、「API キー」を入れる（「〇〇 の API キーを取得する」から取得のページを開ける）。カスタムを選んだときは「接続先 URL」に `/chat/completions` の手前までを入れる。「モデル」は空欄なら既定のモデルを使う。「1 日の上限」を決める（30・60・100・200 回、または上限なし。既定は 100 回）
4. 「接続テスト」を押し、「接続できました」と出たら上部の「保存」を押す。保存しないで戻ろうとすると、保存するかを確かめる

自分の API キーはこの端末の中に暗号化して保存し、選んだ AI サービスへの通信にだけ使います。バックアップや機種変更での移行には含まれないので、新しい端末では入れ直してください。

## 3. 画面の見方

### メイン画面

地図が画面いっぱいに広がり、ほかのものは地図の上と下に重なります。

| 場所 | 内容 |
|---|---|
| 左上のチャンネル名 | 使っているチャンネル（「歴史探訪」など）。タップでチャンネルを選ぶ |
| 右上のボタン | 左から「散歩の記録」（時計）「設定」（歯車）「その他」（︙。中に「周辺を再検索」） |
| 発言のカード（地図の上） | 散策中の様子（経過時間・距離・案内した数）と、話しかけた最新の内容。「もう一度聞く」で読み直し、「これまでの話」で過去の発言を広げる。散策を終えた後は「散策の振り返り」として残り、右上の ✕ で閉じられる |
| 施設の帯（地図の上） | トイレ・水飲み場・自動販売機・休憩所・ベンチの最寄りの距離。タップで地図がそこへ動く |
| お知らせ（地図の上） | API キーの未設定、位置情報がオフ、日本語の読み上げ音声がない、チャンネルのお知らせなど。いちばん大事な 1 件だけを出し、ほかは「ほか n 件」。タップで対処の画面か、お知らせの一覧へ |
| 地図 | 半径 600m のスポットと施設。スポットは丸で、寺社・史跡・文化・自然・お店ほかの 5 つに色分けする。施設は角の丸い四角。現在地の点の扇形は向いている方向。右下のボタンで現在地に戻る。その上のボタンで、北が上と向いている方向が上を切り替える（向いている方向が上のときは、ボタンの矢印が北を指す。選んだ方は次に開いたときも残る）。散策中は、さらに上のマイクで一言を置く（[10](#10-スタジオと一言)） |
| 下のシート | 近い順のスポットの一覧。ふだんは見出しと「散策をはじめる」と最寄りの 2 件、散策中は見出しと「散策を終える」だけを見せる。上に引き上げると全部が出て、色分けの種類で絞り込める（地図も同じく絞る）。過去に訪れた回数も出る |

### スポットの解説

一覧か地図でスポットをタップすると、地図がそこへ動いてそのスポットを大きく描き、下のシートがそのスポットのカード（名前とよみ・種類・距離・宗教や時代などの要点・立ち寄った回数）に替わります。カードの ✕ か戻るで一覧に戻ります。

- 「解説を聞く」: AI がガイド風の解説を作り、できたら読み上げます（作っている間は「準備しています」）。読み上げ中は「止める」で止めます
- 「解説を読む」: 解説を開きます。解説の上に、地図のデータ（OpenStreetMap）からわかること（創建・宗教・文化財・開いている時間・料金など）と、Wikipedia・公式サイトへのリンクを出します。ここは AI を使わないので、解説を作れないときも出ます。「読み上げ」で読み上げ、「停止」で止めます。写真が登録されているスポットでは、Wikimedia Commons の写真を作者・ライセンスとともに出します（既定は Wi-Fi のときだけ）

解説は、どちらかを押したときに初めて作ります。スポットを選んだだけでは AI を呼びません。

スポットまでの徒歩ルートが地図に描かれます。地図の左下の ✕（ルートを消す）で消せます。道を取得できないときは、方向だけを点線で示します。

## 4. 散歩する

1. 「散策をはじめる」を押す。通知が出て、画面を閉じても位置を追い続ける
2. スマートフォンはポケットやかばんに入れて、イヤホンで聞きながら歩く
3. 終えるときは「散策を終える」か、通知の「終了」を押す。散歩の振り返りを話して、記録に残る

### 話しかける場面

| 場面 | 内容 |
|---|---|
| 開始・終了 | あいさつと、距離・時間・案内したスポットの振り返り |
| スポットの 60m 以内に来た | 初めてなら解説、過去に訪れていれば何回目かを踏まえた短い一言。解説では、つながりのある周りの見どころにも触れることがあります |
| 進む先 300m 以内に名の知れた見どころがある | 「この先に〇〇があります」と予告（見どころごとに 1 回。頻度が「静か」では出ない）。着いたら解説します |
| 一定の距離・時間を歩いた | 天気や時間帯に合わせた一言 |
| 同じ場所に 4 分以上いる | 休憩に合わせた一言 |
| 話すことがないまま「雑談の間隔」が過ぎた | 季節・天気・時間帯・歩いてきた道・周りの見どころ・水分や一休み・チャンネルらしい話題を順に、世間話の一言（AI を使えるときだけ。頻度が「静か」では出ない）。ときどき、前置きのあとに季節の唱歌・童謡のメロディを流す（設定の「季節の歌を流す」。歩き始めて 10 分から、1 回の散歩で 2 曲まで、20 分以上空けて。ほかに話すことができたら 1 秒で小さくして止める） |
| 天気が崩れそう（1 時間以内） | 何分後に崩れそうかと備え。雷雨のときは音の鳴る通知も出す |
| 日の入りの 30〜5 分前 | 帰り道を意識する一言 |
| 状況に合う施設が近い | 雨なら休憩所、しばらく歩いたらトイレ、暑い日は水飲み場など |

- 天気の急変・日の入り・施設の案内は**安全のための案内**で、どのチャンネルでも、話しかけの頻度に関係なく知らせます
- 読み上げの間は、ほかのアプリの音楽が小さくなります
- 歩きながら画面を見ないでください。写真や全画面の画像は、立ち止まってから開きます（歩いている間は全画面を開けません）

## 5. チャンネルを選ぶ・変える

チャンネルは、語り手と話題、話しかける場面と頻度をまとめて切り替えるものです。メイン画面の左上のチャンネル名、または設定の「チャンネル」で選びます。散歩の途中でも切り替えられ、切り替えたら新しいチャンネルの一言を読み上げます（その後 1 分はスポットの案内と雑談を控えます）。

| チャンネル | どんな散歩か |
|---|---|
| 標準 | 気心の知れた散歩の友。由来・歴史・見どころ |
| 歴史探訪 | 歴史に詳しい語り部。解説は長め。寺社・史跡・博物館を先に話す |
| 自然観察 | 草花・鳥・水辺・地形。公園・庭園・水辺を先に話す |
| グルメの旅 | 名物・食文化。飲食店・菓子・市場も探して地図に出す（チェーン店は除く） |
| ショッピング | 工芸・商店街。工芸・土産・専門店も探して地図に出す |
| しずかに | 開始・終了のあいさつと安全の案内だけ。タップしたスポットには短い解説を出す |

### 組み込みのチャンネルを自分好みに変える

設定の「チャンネル」の欄で、選んでいるチャンネルごとに次を変えられます。変えた項目だけを保存し、「「チャンネル名」を初期値に戻す」で元に戻ります。

| 項目 | 選べるもの |
|---|---|
| 話しかけの頻度 | 控えめ・ふつう・おしゃべり |
| 話しかける場面 | 初めてのスポットの解説・再訪したスポットの一言・距離・時間の区切り・休憩の声かけ・開始のあいさつ・終了の振り返り・少し先の見どころの予告・話すことがないときの雑談 |
| 解説の長さ | 短め・ふつう・長め |
| 優先する話題 | スポットの種類から複数 |
| 話し方を雰囲気に合わせる | オン・オフ |
| 背景音の種類 | 自動・雨音・波の音・風の音・鳥の声・虫の音・遠くの鐘（「画面と音」の欄の、背景音を流す設定の下に出る） |

| 頻度 | スポット案内の間隔 | 雑談の間隔 | 区切り | 休憩の声かけ |
|---|---|---|---|---|
| 控えめ | 5 分以上 | 6 分以上 | 2km または 30 分 | しない |
| ふつう | 2 分以上 | 3 分以上 | 1km または 15 分 | する |
| おしゃべり | 1 分以上 | 2 分以上 | 500m または 8 分 | する |

語り手と話題の文章は変えられません。

## 6. 配信されているチャンネルを使う

> 本番のリストができるまでは、設定の「チャンネル・リストと試用チケット」は開発者モードのときだけ出ます。ふだんは組み込みのチャンネルだけを使います。

第三者（観光協会・店舗・愛好会など）が作り、運営が審査したチャンネルを取り込めます。

### リストを足す

1. 設定の「チャンネル・リストと試用チケット」を開き、「チャンネル・リストを足す」を押す
2. リストの URL と「リストID（sc1…）」を入れて「足す」を押す
   - リストIDは、運営のサイトなど**このアプリとは別の方法で確かめたもの**を入れてください。そのリストの運営が審査したチャンネルを信用することになります
3. リストのチャンネルが一覧に出る

リストは 1 日ごと（アプリの起動時と散策の開始時）に確かめます。「今すぐ確かめる」で手動でも確かめられます。「このリストを外す」で外すと、そのリストのチャンネルは端末から消えます。

### チャンネルを取り込む

1. 一覧のチャンネルの「取り込んで使う」を押す
2. 「「チャンネル名」を使いますか」と、話す量・解説の長さ・1 時間の散歩で AI を呼ぶ回数の目安が出る。標準のチャンネルより多く呼ぶときは、その旨も出る
3. 「使う」を押すと切り替わる。「使わない」なら取り込んだものを消す

- 第三者のチャンネルの頻度や場面はチャンネル提供者が決めます（変えられません）。ただし、AI を呼ぶ量は 1 日の上限（運営の AI では運営が決めた回数、自分の API キーでは設定の「1 日の上限」）の中で動きます
- 新しい版は、Wi-Fi など従量制でない回線のときに自動で、または「新しい版を取り込む」で取り込みます
- 素材（文字・画像）を出すチャンネルは、選んだときに素材をまとめて取得します。その後の更新は従量制でない回線のときだけです

### 一覧に出る表示

| 表示 | 意味 |
|---|---|
| 取り込み済み | 使える |
| 新しい版を取り込む | 新しい版がある |
| （リストから外れたため使えません） | 取り下げられた。理由がお知らせに出て、標準のチャンネルに戻る |
| リストの期限が切れています | リストを長く確かめられていない。回線をつないで「今すぐ確かめる」 |
| チャンネル提供者の鍵が移し替えられました | 運営の裏付けのある正しい移し替え。そのまま使える |
| チャンネル提供者が裏付けなく変わったため、新しい版は使いません | 安全のため新しい版を拒んだ。前の版をそのまま使う |
| アプリの更新が必要です／このアプリでは使えない形式です | アプリを更新する |

## 7. 散歩の記録

右上の時計（散歩の記録）で、これまでの回数・距離・時間、よく訪れる場所、散歩ごとの日時・距離・時間・使ったチャンネル（途中で変えたら「標準 → 歴史探訪」）を見られます。

- 記録はこの端末の中にだけ保存し、外に送りません。最新 500 件まで残します
- 1 分未満で、スポットの案内もなかった散歩は残しません
- 「記録をすべて削除」で消せます（元に戻せません）

## 8. 画面と音・地図・端末に残すデータ

設定の「画面と音」「地図」の欄で変えます。

| 設定 | 既定 | 説明 |
|---|---|---|
| 画面を雰囲気に合わせる | オン | 時間帯・季節・天気・場所に合わせて画面の色と散策中の絵を変える |
| 散策中に背景音を流す | オフ | 雨音・波・鳥の声などを雰囲気に合わせて流す |
| 音量 | 40% | **車や自転車の近づく音が聞こえる音量にしてください** |
| イヤホンのときだけ流す | オン | オフにするとスピーカーからも流す。イヤホンを外すとすぐ止まる |
| スポットの写真を表示する | オン | Wikimedia Commons の写真 |
| モバイル通信でも写真を取得する | オフ | オフのときは Wi-Fi などでだけ取得する |
| 地図 | 地理院の標準 | 地理院の淡色・写真・標高、OSM の標準、Google の地図・航空写真 |

OSM の標準地図は OpenStreetMap の共用のサーバーから取ります。取れないときは地理院の標準地図で表示し、理由を地図の上に出します。右上のメニューの「周辺を再検索」で、もう一度つなぎます。

Google の地図を使うときは「Google Maps Platform の API キー」を入れます。Google Cloud で請求先を登録し Map Tiles API を有効にしてからキーを作り、「API の制限」で Map Tiles API だけに絞って、割り当て（上限）も設定しておいてください。表示した量に応じてそのアカウントに料金がかかることがあります。

### 端末に残すデータ

設定の「端末に残すデータ」の欄で変えます。

| 設定 | 既定 | 説明 |
|---|---|---|
| スポット検索の結果を残す | オン | 近くで検索した結果と運営のスポットのタイルを残し、新しければ問い合わせずに使う。問い合わせに失敗したときも、残っている結果を出す |
| 問い合わせずに使う期間 | 7 日 | 1・3・7・30 日。これより古い結果は、問い合わせのあいだだけ出す。結果は最長 90 日残す |

「スポット検索の結果を消す」で、残した結果をすぐに消せます。残した結果から、おおよそ歩いた場所が分かります。「記録をすべて削除」でも一緒に消えます。

## 9. 天気・日の入り・施設の知らせ

設定の「天気・日の入り・施設の知らせ」の欄で、安全の案内をどんなときに出すかを変えられます。「既定値に戻す」で戻ります。

| 案内 | 項目（既定値） |
|---|---|
| 天気の急変 | 何分先までの予報で知らせるか（60 分）、同じ種類の予告の間隔（60 分）、「強い雨」とする雨量（8mm/h） |
| 日の入り | 何分前から知らせるか（30 分）、何分前を過ぎたら知らせないか（5 分） |
| トイレの案内 | 歩き始めてから（20 分）、案内する距離（100m）、次の案内までの間隔（45 分） |
| 水分補給の案内（暑い日） | 歩き始めてから（15 分）、暑いとする気温（25℃）、案内する距離（80m）、間隔（30 分） |
| ひと休みの案内（ベンチ・休憩所） | 歩き始めてから（40 分）、案内する距離（60m）、間隔（40 分） |
| 雨宿りの案内（雨・雪のとき） | 案内する距離（150m）、間隔（20 分） |

範囲の外の値や、案内が出なくなる組み合わせ（日の入りの 2 つの値の大小が逆）は保存できず、理由が出ます。

## 10. スタジオと一言

**スタジオ**は、運営が認めた店・地域が出すお知らせです。**一言**は、その場所を歩いた人が残した短い投稿です。2 つは別の種類で、どちらも近くを歩く人に読み上げます。設定でオンにしたときだけ聞こえます。

### 聞く

設定の「スタジオ（店や地域のお知らせ）」の欄で「スタジオを聞く」を、「一言」の欄で「一言を聞く」をオンにします。初めてオンにするときは、知らない人の一言やお知らせが読み上げられることの説明が出ます。

| 種類 | 読み方 | 上限 |
|---|---|---|
| 一言 | 「（スポット名）のそばで、この辺りを通った人の一言です。…」 | 1 時間に 10 件 |
| スタジオ | 「（出した人の名前）からのお知らせです。…」。音声があれば続けて流す | 1 時間に 2 件。出した人が決めた時間帯だけ |

- 散策中、話すことがなく、前の発言から 1 分空いたときに 1 つだけ読みます。同じ一言は繰り返さず、同じお知らせは 1 日 1 回です
- 発言のカードには「一言（この辺りを通った人）」「お知らせ（出した人の名前）」と出ます。「これまでの話」で広げると、一言には「いいね」「ブロック」「通報」、お知らせには「音声を聞く」「通報」が出ます
- **ブロック**すると、その一言を置いた人の一言は、これから届きません。相手には知らされません。設定の「一言」の「ブロックした人を見る」で解けます
- **通報**は理由（安全を損なう・人を傷つける・宣伝・権利の侵害・聞かせるのに合わない・そのほか）を選んで運営に送ります。3 人から通報された一言は、だれにも届かなくなり、運営が確かめます

### 一言を置く

散策中に、地図の右下のマイクを押します（端末で声を文字にできる Android 12 以上の端末だけ）。

1. 初めては、一言の利用規約に同意します。人を傷つけること、人の居場所、連絡先、宣伝は置けません
2. 話すと、端末の中で文字になります（60 文字まで）。**声そのものは送りません**
3. 文を確かめます。直すことも、期限（1 時間・24 時間・7 日）と近くのスポットの名前を付けるかも選べます。触らなければ 3 秒後に置きます
4. 運営の AI が確かめてから置きます。置けるのは 1 日 10 件までです

一言には名前が出ず、場所は約 150m の範囲に丸めます。設定の「自分の一言を見る」で、置いた一言、聞いた人のおおよその数（3 人未満は出ない）、いいねの数を見られ、期限の前に消せます。

一言の中身は置いた人、スタジオの中身は出した人（素材提供者）のものです。運営は通報を受けて消すことがあり、問題のある一言を置いた端末は一言を置けなくなることがあります（[一言の利用規約](https://github.com/duwenji/yorisoi-platform/blob/main/docs/policies/notes-terms.md)）。

## 11. 問題を知らせる

AI の発言やチャンネルにおかしな点（誤り、危険な誘い、不快な内容など）があったら知らせてください。

| 知らせる対象 | 操作 |
|---|---|
| ある発言 | 発言のカードの「これまでの話」で広げ、その発言の「この発言を知らせる」 |
| 配信されているチャンネル | 「チャンネル・リストと試用チケット」の一覧で、そのチャンネルの「問題を知らせる」 |

メールのアプリに下書きが開きます。冒頭に何が問題だったかを書いて、自分で送ってください。下書きにはチャンネル・発言の時刻と内容・アプリの版が入り、**位置は入りません**（場所を伝えたいときだけ自分で書き足してください）。宛先は、そのチャンネルを載せたリストの運営、組み込みのチャンネルならアプリの問い合わせ先です。

AI の発言には誤りがありえます。事実は、現地の案内板や公式の情報で確かめてください。

## 12. 送る情報と費用

| 送り先 | 送るもの | いつ |
|---|---|---|
| AI サービス（運営の AI では運営の中継を通して。中継は内容を保存しない） | スポット名・距離・日時・天気・雰囲気・前回話した内容など。既定では緯度経度と経路は送らない | 解説と話しかけのとき |
| 運営のスポットのタイルの配信 | タイルの名前（約 4km × 5km の区画。緯度経度は送らない） | スポットの検索（500m 動くごと。新しいタイルが残っていれば送らない）。散歩していないときに、よく通る道のぶんを前もって取る |
| 運営の季節の歌の配信（スポットのタイルと同じ配信） | 一覧と曲のファイルの名前（位置は送らない） | 散歩していないとき、1 日 1 回。音は Wi-Fi などのときだけ。「季節の歌を流す」をオフにすれば取らない |
| OpenStreetMap（Overpass） | 現在地のまわりの範囲 | タイルが取れないときだけのスポットの検索（近くで検索した結果が残っていれば送らない） |
| OSRM（経路検索） | 現在地とスポットの緯度経度 | ルートを描くとき |
| Open-Meteo（天気） | 現在地の緯度経度 | 散歩の開始時と 15 分ごと |
| Wikimedia | スポットの Wikidata の ID・ファイル名（緯度経度は送らない） | 写真の取得 |
| Google（選んだときだけ） | 表示している地図の範囲 | 地図の表示 |
| 足したリスト | 位置も散策者の情報も送らない | リスト・チャンネル・素材の取得 |
| 運営のスタジオと一言（設定でオンにしたときなど） | 取るとき: 周辺の区画の名前（約 1.2km × 0.6km）。置くとき: 一言の文字・区画（約 150m）・スポット名・期限。散歩の終わり: 聞いた・いいねした一言とスタジオの ID。緯度経度と声は送らない | 散策中 5 分おき、一言を置くとき、散策の終わり、通報・ブロックのとき |

- 設定の「AI に緯度経度と歩いた経路を送る」をオンにすると、場所に即した話になるかわりに、緯度経度と間引いた経路も AI に送ります
- 運営の AI の費用は運営が持ちます。自分の API キーの費用は、呼んだ回数と長さで決まります。どちらも 1 日の上限に達した日は、AI を使わず定型文で案内します（安全の案内は続きます）。キャッシュ済みの解説は回数に数えません

詳しくは[プライバシーポリシー](https://github.com/duwenji/yorisoi-sanpoguide/blob/main/docs/policies/privacy-policy.md)を見てください。

## 13. 困ったとき

| 起きていること | 対処 |
|---|---|
| 「AI の API キーが未設定のため、簡易解説で動作しています」 | 設定で API キーを入れ、「接続テスト」してから保存する。運営の AI に切り替えてもよい |
| 接続テストが失敗する | キーの写し間違い、サービスの残高・請求先、モデル名、カスタムなら接続先 URL を確かめる |
| 「端末の位置情報がオフのため…」 | 帯をタップして端末の位置情報をオンにする |
| 「端末に日本語の読み上げ音声がないため…」・案内が日本語で読まれない | 帯をタップして日本語（日本）の音声データを追加する。端末の設定の「テキスト読み上げの出力」で、優先するエンジンを「Google の音声サービス」に、言語を日本語にする |
| スポットが出ない・検索が失敗する | 公開の地図サーバーが混んでいることがある。少し待って右上の「その他」（︙）の「周辺を再検索」 |
| 話しかけが急に決まった文になった | 1 日の上限に達したか、AI の呼び出しに失敗した。設定の「AI」の欄で、運営の AI なら「今日の残り」、自分の API キーなら「今日は◯回使いました」を確かめる |
| 背景音が鳴らない | 「散策中に背景音を流す」がオンか、イヤホンをつないでいるか、ほかのアプリで音楽を再生していないか |
| 画面を閉じると案内が止まる | 端末の電池の最適化でアプリが止められていることがある。散策ガイドを最適化の対象から外す |
| 話が長い・場所の言い方がずれる | モデルによって差がある。解説の長さを短めにする、別のモデルを試す |
| 「メールのアプリがありません」 | 表示された宛先に、ほかの方法でメールを送る |
| 一言・スタジオが聞こえない | 設定の「スタジオ」「一言」の欄でオンになっているか。運営の AI が使えないビルドでは使えない。近くに一言・スタジオがないこともある |
| マイクのボタンが出ない | 散策中だけ出る。端末で声を文字にできない（Android 11 以下など）端末では出ない |
| 「聞き取れませんでした」 | 静かなところで、もう一度マイクを押して話す |
| 「この端末からは一言を置けません」 | 問題のある一言を置いたため、運営が一言を置けないようにしている（聞くことはできる） |
